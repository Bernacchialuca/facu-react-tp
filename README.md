# TecnoNova

## Cómo levantarlo

```bash
npm install
npm run dev
```

Abrir `http://localhost:5173` en el navegador.

## Vistas

| Ruta            | Vista                                     |
| --------------- | ----------------------------------------- |
| `/`             | Inicio con productos destacados           |
| `/productos`    | Catálogo de productos                     |
| `/producto/:id` | Detalle de un producto                    |
| `/carrito`      | Carrito de compras                        |
